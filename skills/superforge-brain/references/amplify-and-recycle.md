# Amplify and Recycle — range dial, push ladder, cross-breeding, the ledger

v4 fixed the *selection* problem: ordinary-but-needed ideas no longer get
deleted, and killed cells stay visible. Two complaints from real runs remained:

1. **"The ideas still aren't very good."** Most of the ideas were correct, but
   few of them were exciting.
2. **"I want to choose how safe the answer is, and pick things back up."** An
   all-or-nothing purge of the ordinary is wrong. So is a list that is only
   safe. People like a safe option next to the bold one, and they want to
   reach into the discard pile and say *"that one, push it."*

This file answers both. §1 is the dial. §2–§3 add the two generation steps the
sweep cannot do by construction. §4 is the fix for quality loss inside the
sweep itself. §5 is the persistence that makes recycling possible in a later
session.

---

## 1. The range dial and the three lanes

The dial decides **how the final shortlist is allocated**. It does not decide
what gets generated by the sweep, and it never deletes anything.

### Lanes are derived, never stored

| Lane | Comes from | Sorted within the lane by |
|---|---|---|
| **定番 — Safe** | Workhorse quadrant (incl. `revisited` ban-list entries) | 事業軸, then the strength of the win-path code |
| **本命 — Core** | Hero quadrant | 独創軸 + 事業軸 |
| **飛び — Far** | Lab quadrant, plus any `open_world` rung whatever its quadrant | 独創軸 |

A card's quadrant comes from its scores at render time (`value-classification.md`
§1). Its lane follows from the quadrant, and the `open_world` tag can move it
to 飛び. Nobody writes `"lane": "本命"` into the ledger. A stored label can
disagree with the scores beside it, and when it does, readers believe the label.

### Quotas (shortlist of 10, scale proportionally)

| Dial | 定番 | 本命 | 飛び | Seeds for the push ladder | Ladder depth | Cross-breed |
|---|---|---|---|---|---|---|
| `grounded` | 5 | 3 | 2 | top 2 Workhorse + top 2 Hero | to L2 | no |
| `balanced` | 3 | 4 | 3 | top 3 Hero + top 2 Workhorse + top 1 Lab | L3 on the top 3 seeds, L2 on the rest | top 3 pairs |
| `far-out` | 2 | 3 | 5 | top 3 Hero + top 3 Lab + top 2 Workhorse | L3 on every seed | top 8 pairs |

Recycled cells (§5) are **always** seeds, on top of these counts.

**When a lane can't fill its quota, leave the slots empty and say so.** If
only one Hero exists, the shortlist shows one Hero and an empty slot that reads
「本命が1件しか生まれなかった」. Don't fill the gap with the best Lab card. A
padded lane hides the most useful finding of the run, which is that this space
produced almost nothing new.

### Changing the dial after the run

Lanes come from scores, so changing the dial reallocates the shortlist for
free. It doesn't rerun anything. The HTML does this live (`idea-map-output.md`
§Range dial). The one thing a dial change can't do for free is run the ladder
deeper or start cross-breeding. If the user moves from `grounded` to `far-out`,
offer `/superforge-brain push … --to far-out` on the new seeds. Don't silently
present L2 cards as if they were L3.

## 2. Push ladder

Every cell is **one** transformation of **one** element. That makes the sweep
exhaustive. It also caps how far any single idea can travel from the obvious.
A good idea is usually a decent idea pushed two more steps, and the sweep has
no step for "now push this one further."

For each seed, write three rungs, each a full card:

| Rung | Rule | Must also state |
|---|---|---|
| **L1 grounded** | The smallest version that could ship in 30 days. Closed World intact. Nothing added. | the one screen, shelf, or service moment that delivers the value |
| **L2 stretch** | Break **one more** premise of the seed than the seed itself broke. Closed World intact. | which premise, quoted as the bias sentence it breaks |
| **L3 far-out** | Allowed to **import one outside element** or **jump ten years**. Tag `open_world`. | 「今はなぜ無理か」 (cost, law, behaviour, technology — and what would have to change) and 「今日できる最初の一歩」 |

Rules:

- **Rungs are independent cards**, judged blind by the same protocol
  (`ideation-tools.md` §4.3). A rung does not inherit its parent's scores, so
  an L1 can beat its own seed, which happens often and is worth knowing.
- **L3 without both extra fields is not an L3.** "Far-out" with no account of
  why it is impossible today is just vague. "Far-out" with no first step is a
  poster. Either way it goes back for a rewrite, not to the judge.
- **An L1 that equals the seed is a skipped rung.** If the seed already *is*
  the 30-day version, say so in the L1 slot instead of copying it.
- **IDs:** `<seed_id>.L1`, `<seed_id>.L2`, `<seed_id>.L3`, each with
  `parent: <seed_id>` and `rung: 1|2|3`.

## 3. Cross-breeding

Some of the best concepts are two half-ideas from different corners of the
space: a Subtraction on the counter plus an Attribute Dependency on the
weather. No single cell can be both.

1. **Candidate pairs** come from survivors in **different techniques and
   different elements**. Two cells from the same element and technique are a
   duplicate, not a cross.
2. **Compatibility.** The two broken biases must not contradict each other.
   「店員がいない」 and 「店員が客の名前を覚えている」 do not cross.
3. **Rank** the compatible pairs by the sum of their two 独創軸 scores, and
   take the dial's count from §1.
4. **Write the hybrid** as a full card that names **what each parent
   contributes**, one clause each. If you can't name the contribution, there
   is no hybrid, only two ideas next to each other.
5. Tag `hybrid`, ID `X<n>`, with `parents: [a, b]`. Judge it blind.

## 4. Why sweeps go flat, and the fix

Two causes account for most "the ideas aren't good" runs. Neither is a
problem with the method.

### 4.1 Fatigue inside one long context

By cell 200 of a single context, the model is completing its own earlier
output. The forms converge: everything becomes "a subscription," "a
community," "an app that notifies." Hand-off rules can't fix this, because
the drift happens inside the context.

**Fix (Claude Code): `workflows/superforge-brain-sweep.js`.** Each batch of
1–3 elements runs in its own agent. The agent sees only the brief, its element
rows, the global banned three, and that element's obvious ideas. It never sees
another element's cells. Kill checking, card writing, judging, pushing, and
crossing each run in separate agents too, so the judge never sees how an idea
was reached.

**Prose fallback (Claude.ai, or no workflow runtime).** Before each element,
re-read only the brief, that element's row, and the banned list. Keep a running
**shape ledger**: one line per cell naming the form's shape in two words
(「無人化」「時間分割」「定額化」「共有化」…). If a shape already appears three
times in the run, the next cell that reaches for it must pick another form.
The ledger is cheap, and it is what a fresh context gives you for free.

### 4.2 Abstract cards

A card written only in abstract nouns (「体験価値の向上」「新しいつながり」)
looks deep and can't be built. The judge can't tell a vague good idea from a
vague bad one, so both score in the middle and the shortlist goes grey.

**Fix:** every card carries a `scene`: who, where, which moment, and what they
see or do, in one or two sentences. Example: 「雨の火曜18時、駅前の店で、傘を
畳んだ客がレジ横の画面に目をやると、今日の雨量に応じて値下がりした温かい一品が
並んでいる」. The judge is told to score Wow low on any card whose scene is
generic or missing. A card whose scene can't be written gets rewritten
concretely or scores low. Vagueness never gets the benefit of the doubt.

## 5. The ledger file and follow-up commands

### 5.1 `docs/product-idea.ledger.json`

The HTML used to be the only place the full ledger lived, so a later session
couldn't act on a single cell without re-running the sweep. The ledger is now
its own file. The HTML embeds a byte-identical copy.

```json
{
  "schema": "breakbias-ledger/1",
  "subject": "…",
  "domain": "A",
  "resolution": "standard",
  "dial": "balanced",
  "generated": "YYYY-MM-DD",
  "elements": [
    {"id": "E01", "name": "…", "lens": "structural", "bias": "…", "break_potential": "high", "obvious": ["…", "…", "…"], "swept": true}
  ],
  "banned": [
    {"id": "B1", "idea": "…", "revisit": {"win_path": "w:geo", "reason": "…", "card_id": "B1"}}
  ],
  "cells": [
    {
      "id": "E01-SUB-1", "element_id": "E01", "technique": "Subtraction", "sub_method": "除去のみ",
      "bias": "…", "form": "…", "provider": "…", "user": "…", "concept": "…",
      "status": "judged", "kill_code": null, "kill_reason": null,
      "prior_art": true, "win_path": "w:exec", "win_reason": "…",
      "salvaged": false, "merged_into": null, "recycled": false
    }
  ],
  "cards": [
    {
      "id": "E01-SUB-1", "source": "sweep",
      "parent": null, "rung": null, "parents": null, "open_world": false,
      "name": "…", "one_line": "…", "scene": "…", "why_surprising": "…",
      "user_value": "…", "business_value": "…", "price": "…", "risks": "…",
      "next_experiment": "…", "impossible_today": null, "first_step": null,
      "scores": {"novelty": 7, "wow": 6, "user": 8, "company": 6},
      "effort": 3, "lab_reentry": null, "market": null
    }
  ]
}
```

- `source` is one of `sweep` · `revisited` · `push` · `hybrid` · `recycled`.
- `cells` holds every generated cell, killed ones included. `cards` holds
  every cell that was developed and judged, plus the rungs, hybrids, and
  revisited banned ideas, which have no cell of their own.
- **No quadrant, lane, or axis sum appears anywhere.** They are computed from
  `scores` by whatever reads the file.
- `effort` is 1 (an afternoon) to 5 (a funded team for a year). Write
  `null` rather than guess. The HTML puts null-effort cards in an "unscored"
  tray instead of placing them.
- Cells that should have run and didn't stay `"status": "todo"`, and the HTML
  header turns red if any exist. Elements left out on purpose by the
  resolution (`quick` sweeps only the highest-potential elements) get
  `"swept": false` and no cells. The header reports them as
  `elements swept n / total`, not as unfinished work.

### 5.2 Commands

Each command reads the ledger, appends to it, then regenerates both
`docs/product-idea.md` and `docs/product-idea.html` in the same turn. None of
them re-runs the sweep.

| Command | What happens |
|---|---|
| `/superforge-brain recycle <id…> [--push grounded\|stretch\|far-out]` | Each cell becomes `recycled: true`, gets a card (`source: recycled`) if it has none, and is judged blind. With `--push`, it also climbs the ladder to that rung (`grounded` = L1, `stretch` = L2, `far-out` = L3). A recycled cell that was killed keeps its original `kill_code` in the record, so the reader can see it was picked back up. |
| `/superforge-brain push <id…> [--to stretch\|far-out]` | Run the push ladder on cards that already exist. Default `--to far-out`. |
| `/superforge-brain cross <id> <id>` | One hybrid, under the §3 rules. If the pair fails compatibility, say why and write nothing. |
| `/superforge-brain dial grounded\|balanced\|far-out` | Rewrite `dial` and the shortlist in the markdown. No generation. If the new dial calls for a deeper ladder than exists, list the `push` command that would provide it. |

Run the user's argument through the same rules as the original sweep. A
recycle request is not permission to skip the judge, and it is not permission
to score a card higher because the user liked it. The user's choice decides
**what gets developed**. The judge still decides **how it scores**.
